One letter, A for coffee: the bolder stance, and the judge weighs vividness first. Coffee lands as the fuller, more alive answer — the first cup of the day, dark and hot and awake — where tea reads quieter and softer. The program writes exactly that one letter to `/output/entry.txt` and self-checks the gate (exactly 1 character, a single letter A–Z, not only whitespace) before and after writing.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

Node 22, standard library only. No clock, no randomness, no network — two runs write byte-identical output.
